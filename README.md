# ELO301_G13_ST_ToF_shield

STM32 Nucleo-64 shield PCB project for using ST Microelectronics VL53L7CX Time of Flight (ToF) 8x8 multizone ranging sensor. Designed by Tomas Mercado, Vicente Osorio and Felipe Rojas at Universidad Tecnica Federico Santa Maria, Valparaiso, in the context of the course ELO301 ``Electronic Equipment Design'' under the supervision of Alvaro Aguirre.
